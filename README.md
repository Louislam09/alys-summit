# Alys Summit

![Banner](icon.png)

A fast-paced, precision 2D platformer featuring fluid movement mechanics, responsive physics, and challenging level design.

## Features

- **Precision Platforming**: Tight, responsive character controls designed for skill-based movement.
- **Dynamic Abilities**: Dash mechanics, wall jumps, stamina management, and momentum physics.
- **Challenging Hazards**: Spikes, collapsing platforms, moving obstacles, and checkpoints.
- **Retro Visuals**: Clean pixel art aesthetics and smooth sprite animations.

## Getting Started

### Prerequisites
- [Godot Engine](https://godotengine.org/download)

### Running the Project
1. Clone the repository:
   ```bash
   git clone git@github.com:Louislam09/alys-summit.git
   cd alys-summit
   ```
2. Open Godot Engine, click **Import**, and select `project.godot`.
3. Click **Run** or press `F5`.

## Controls

- **Move**: `A` / `D` or `Left` / `Right`
- **Jump**: `Space` or `Z`
- **Dash**: `Shift` or `X`
- **Climb / Grab**: `C` or `Up`
